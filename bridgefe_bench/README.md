# BridgeFE-Bench

33 parametric benchmark cases: 30 main A–C cases and 3 long units S01–S03. inputs/, free_text/ and boundary/ provide descriptions; problems/ stores reference decisions/responses; src/ generates the benchmark; validation_report.md records numerical checks.

Authors confirmed on 2026-10-16: reference answers were reviewed by two bridge engineers. This supersedes the pending-review note preserved in ../docs/legacy/bridgefe_bench_README.md. Reviewer names, dates and signed review documents are not included.

These are idealized benchmarks, not measured field bridge responses. Parameters derive partly from cited standard drawings. Original drawings and complete standards are excluded. Rights for derived tables and provision wording still require release review.
