## 参考答案

**决策层**（`reference_decisions`，主评估）：每项决策包含类别（`modeling_rule` / `code_parameter` / `topology`，对应论文 3.5 节的错误分类）、取值、单位与依据编号。包括结构体系、截面 A 与 I、混凝土弹性模量、重度与自重、每条支承线的支座类型、数量、约束自由度、形状系数、Kv 与 Kh、墩柱长度与截面、设计车道数、横向折减系数、qk、各跨 Pk、冲击系数 μ。每题 25–79 项。

**响应层**（`reference_responses`，辅助核对，容差 0.1%）：
- 自重支座反力（各支承线）、各跨跨中弯矩（下缘受拉为正）、中间支点弯矩；
- 前三阶竖向弯曲频率，其中一阶用于计算 μ；
- 车道荷载各控制截面弯矩，以及最大正弯矩与最大负弯矩（含冲击系数、车道数与横向折减）。

A 档用解析解：两端弹簧支承梁的精确频率方程。B、C、S 档用独立编写的 OpenSeesPy 参考模型，不复用任何被测方法的代码。车道荷载按影响线计算：弹性梁单元内影响线为三次多项式，逐单元精确拟合后，对同号区段解析积分、解析求峰值，结果与网格无关。

## 建模约定（详见 `rules.json`）

- 二维单梁模型，线弹性；多片预制梁合并为单梁，A、I 取单片中梁跨中截面乘以片数。
- 预制梁截面取自浙江省交通运输厅《装配式预应力混凝土T梁通用图》《装配式预应力混凝土小箱梁通用图》（浙交〔2024〕140 号）中梁跨中截面：T 梁 20/25/30/40 m（梁高 1.35/1.70/2.00/2.50 m），小箱梁 25/30 m（梁高 1.40/1.60 m）。理想化时不计 2% 横坡和 r = 5 cm 圆弧倒角。预制梁题目只从这些跨径档位中抽样。
- 球形支座按竖向刚性支承、转动自由，固定型纵向约束、活动型纵向自由。
- 板式橡胶支座用 zeroLength 弹簧：Kv = Ae / [te (1/Ee + 1/Eb)]，Ee = 5.4 Ge S²，Eb = 2000 MPa；Kh = Ge Ae / te；四氟滑板支座纵向自由。
- 支座与墩顶置于主梁轴线标高，不计偏心；墩柱墩底固结，双柱合并。
- 恒载只计主梁自重，重度取 26 kN/m³（题目另有规定时从其规定），质量取一致质量。
- 车道荷载：qk 满布于同号影响线区段；Pk 按所在跨的计算跨径取值；μ 由有限元一阶竖向频率计算，正、负弯矩采用同一 μ。
